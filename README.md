# Star Gazing Discord Server Website

A modern, responsive website for the **Star Gazing** Discord community and service server.

## 🌟 Features

- **Home Page** - Welcome message, server information, and owner's greeting
- **Rules Page** - Complete server rules with punishment system
- **Services Page** - Showcase of development, design, and setup services
- **Survey Page** - Embedded Google Forms for community feedback
- **Boost Perks** - Detailed descriptions of server booster benefits
- **Other Servers** - Links to related Discord communities

## 🎨 Design

- **Theme**: Space/Galaxy with Star Gazing aesthetic
- **Colors**: Deep navy background with gold, purple, and blue accents
- **Typography**: Orbitron (headings) + Inter (body text)
- **Effects**: Animated stars, glowing text, smooth transitions

## 📁 File Structure


## 🚀 Quick Start

1. Clone this repository
2. Open `index.html` in a web browser
3. Update the survey form link in `survey.html`
4. Customize content in `script.js` as needed

## 📝 Customization

### Update Owner Messages
Edit the `ownerMessages` array in `script.js`

### Add/Edit Services
Modify the `services` array in `script.js`

### Update Server Links
Edit the `servers` array in `script.js` or update the Discord invite link in `index.html`

### Survey Form
Replace `YOUR_FORM_ID` in `survey.html` with your Google Forms embed link
